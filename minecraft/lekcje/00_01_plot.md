# Płot z 10 bloków

Zrobisz płot długi na 10 bloków. Teoria jest w [bloki/plot.md](../bloki/plot.md).

## Kod

Wklej to w Code Builderze. Zostaw wcięcia. Jak linie w środku będą przy lewej krawędzi, program się nie uruchomi.

```python
def zbuduj_plot():
    dlugosc = 10
    for krok in range(dlugosc):
        blocks.place(OAK_FENCE, pos_local(krok, 0, 2))

player.on_chat("plot", zbuduj_plot)
```

`dlugosc` to 10. Pętla stawia tyle słupków, jeden obok drugiego, dwa bloki przed tobą.

Ostatnia linia mówi grze: gdy w czacie wpiszesz `plot`, uruchom funkcję `zbuduj_plot`.

## Jak uruchomić

1. Wejdź do świata, w którym działa Code Builder.
2. Stań na płaskim miejscu. Popatrz tam, gdzie ma iść płot. Nie kręć myszką, dopóki słupki nie staną.
3. Otwórz Code Builder przyciskiem C.
4. Wybierz Python. Wklej kod.
5. Naciśnij zielony przycisk startu.
6. Wróć do gry. Naciśnij T, wpisz `plot` i naciśnij Enter.

Obok ciebie, w lewo i dwa bloki do przodu, stanie linia 10 słupków.
