# Domek

Lekcja: [domek](../lekcje/01_01_domek.md)

`blocks.fill` wypełnia prostokąt od jednego rogu do drugiego. `FillOperation.REPLACE` zamienia bloki, które tam już
stoją.

| nazwa w kodzie  | co to jest               | gdzie w domku            |
|-----------------|--------------------------|--------------------------|
| `PLANKS_OAK`    | deski dębowe             | podłoga                  |
| `PLANKS_SPRUCE` | deski świerkowe          | sufit                    |
| `STONE_BRICKS`  | cegły z kamienia         | tylna ściana             |
| `PLANKS_BIRCH`  | deski brzozowe           | lewa ściana              |
| `SANDSTONE`     | piaskowiec               | prawa ściana             |
| `BRICKS`        | cegły                    | przednia ściana          |
| `OAK_DOOR`      | drzwi dębowe             | środek przedniej ściany  |
| `AIR`           | powietrze, puste miejsce | okna w bocznych ścianach |
