pos(a, b, c)

pos(a, b, c)

To miejsce liczone od Twoich stóp.

pos(0, 0, 0) — Twoje stopy.

Która liczba za co

liczba plus minus
a wschód zachód
b góra dół
c południe północ

Twarzą na północ

  • przed sobą — północ — minus c
  • za sobą — południe — plus c
  • po prawej — wschód — plus a
  • po lewej — zachód — minus a
  • b — góra albo dół, niezależnie od twarzy

Przykłady

blocks.place(GOLD_BLOCK, pos(0, 2, 0))      // dwa w górę, nad głową
blocks.place(DIAMOND_BLOCK, pos(3, 0, 0))   // trzy na wschód
blocks.place(IRON_BLOCK, pos(-2, 0, 0))     // dwa na zachód
blocks.place(BLUE_WOOL, pos(0, 0, -3))      // trzy na północ, przed sobą
blocks.place(RED_WOOL, pos(0, 0, 3))        // trzy na południe, za sobą
blocks.place(STONE, pos(0, -1, 0))          // jeden w dół, pod stopami
blocks.place(EMERALD_BLOCK, pos(2, 1, -1))  // 2 wschód, 1 góra, 1 północ
